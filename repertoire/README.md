## Use [v2](v2/) — two files

Import `v2/etude-white-core.pgn` and `v2/etude-black-core.pgn` into En Croissant
(Files → Add New → from PGN), **separately**, then point the repertoire trainer
at whichever side you are drilling. Move up to `-standard` and then `-complete`
as each becomes automatic. Six files exist; two are ever in use.

Everything else about the tiers is in [v2/README.md](v2/README.md), including
the one caveat that matters: the moves are gated at depth 34–50 and sound, but
the trap annotations are provisional until `replicate.mjs` has run.

[v1/](v1/) is the 2026-08-07 generation, kept for comparison. It is shallower
(deepest ply 13 against v2's 19–20) and was built from a 367k-game band book
against v2's 8M. Nothing needs it except a diff.

## Rebuilding

Needs the databases under `db/`, which are gitignored and must be re-fetched —
see [scripts/repertoire/README.md](../scripts/repertoire/README.md).

```
npm run rep:build       # the 1.d4 + Black deck, ~4h
npm run rep:build:e4    # the 1.e4 deck
npm run rep:decks       # re-stage the tiers into v2/
npm run rep:audit       # re-grade every prescribed move against the index
npm run rep:study       # what to learn first, ranked
```
